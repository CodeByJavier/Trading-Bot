Controlar el bot

Los controles están en GitHub y solo tú puedes usarlos con tu sesión iniciada. Pulsa Abrir controles, luego Run workflow, elige la acción y vuelve a pulsar Run workflow. El panel se actualiza en un par de minutos.

pausar

Deja de operar, pero sigue aprendiendo.

reanudar

Vuelve a operar.

vender_y_pausar

Vende lo que tenga al precio actual y se pausa.

cambiar_umbrales

Más o menos exigente para comprar y vender.

reiniciar_simulacion

Empieza de cero (puedes cambiar capital y moneda).
